
# 🤖 ربات پیام‌رسان ناشناس تلگرام

یه ربات ساده برای ارسال پیام‌های ناشناس به ادمین با قابلیت مدیریت کاربران

---

## ✨ امکانات

- 📨 ارسال پیام ناشناس به ادمین
- 📎 پشتیبانی از عکس، ویدیو، فایل، گیف و...
- 🚫 مسدود کردن کاربران با دکمه
- 📊 آمار کامل کاربران و پیام‌ها
- 📢 ارسال پیام گروهی به همه کاربران
- 💾 ذخیره‌سازی دائمی داده‌ها

---

## 🚀 راه‌اندازی سریع

### مرحله ۱: ساخت ربات تلگرام

1. برو به [@BotFather](https://t.me/BotFather) در تلگرام
2. دستور `/newbot` رو بزن
3. یه اسم و یوزرنیم برای ربات انتخاب کن
4. **توکن** دریافتی رو کپی کن (یه متن مثل `8656405448:AAE1D0...`)

### مرحله ۲: گرفتن آیدی ادمین

1. برو به [@userinfobot](https://t.me/userinfobot)
2. دستور `/start` رو بزن
3. **آیدی عددی** خودت رو کپی کن (مثل `7060511074`)

### مرحله ۳: دیپلوی روی Cloudflare

1. وارد [Cloudflare](https://dash.cloudflare.com) بشو
2. از منوی سمت چپ برو به **Workers & Pages**
3. روی **Create application** کلیک کن
4. **Create Worker** رو انتخاب کن
5. یه اسم برای Worker انتخاب کن (مثل `anonymous-bot`)
6. روی **Deploy** کلیک کن
7. برو به تب **Edit code**
8. **همه کدهای داخل ویرایشگر رو پاک کن**
9. **کد کامل ربات** که در اختیار داری رو کپی کن و جایگذاری کن
10. برو به تب **Settings** > **Variables**
11. دو متغیر زیر رو اضافه کن:
    - `BOT_TOKEN` = توکن ربات (از مرحله ۱)
    - `ADMIN_ID` = آیدی ادمین (از مرحله ۲)
12. روی **Save and deploy** کلیک کن

### مرحله ۴: تنظیم Webhook

1. آدرس Worker خودت رو کپی کن (مثل `https://anonymous-bot.workers.dev`)
2. تو یه مرورگر جدید این آدرس رو باز کن:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=<WORKER_URL>
```

3. به جای `<TOKEN>` توکن ربات و به جای `<WORKER_URL>` آدرس Worker رو بذار

**مثال:**
```
https://api.telegram.org/bot8656405448:AAE1D0.../setWebhook?url=https://anonymous-bot.workers.dev
```

4. اگه پیام `{"ok":true}` رو دیدی، یعنی ربات راه‌اندازی شده! ✅

## 📱 دستورات

### کاربران عادی:
- `/start` - شروع کار با ربات

### ادمین:
- `/stats` - مشاهده آمار کامل
- `/blocked` - لیست کاربران مسدود شده
- `/unblock [آیدی]` - رفع مسدودی کاربر
- `/broadcast [متن]` - ارسال پیام به همه کاربران
- `/export` - خروجی گرفتن از لیست کاربران

## 💡 نحوه استفاده

### کاربر:
1. ربات رو استارت کن (`/start`)
2. هر پیامی که دوست داری بفرست (متن، عکس، فیلم، فایل و...)
3. منتظر پاسخ ادمین باش

### ادمین:
1. پیام کاربر به صورت فوروارد شده برات میاد
2. برای پاسخ، روی پیام فوروارد شده **ریپلی** بزن و جواب رو بنویس
3. برای مسدود کردن کاربر، روی دکمه **"🚫 بلاک کاربر"** کلیک کن
4. برای رفع مسدودی از دستور `/unblock [آیدی]` استفاده کن

## 💾 تنظیم KV Storage (اختیاری)

برای اینکه داده‌ها بعد از ریستارت ربات پاک نشن:

1. در Cloudflare برو به **Workers & Pages** > **KV**
2. روی **Create namespace** کلیک کن و اسمش رو بذار `MY_KV`
3. برگرد به Worker خودت
4. برو به **Settings** > **Variables**
5. در بخش **KV Namespace Bindings** روی **Add binding** کلیک کن
6. `Variable name`: `MY_KV`
7. `KV namespace`: `MY_KV` رو انتخاب کن
8. روی **Save** کلیک کن

## 🔧 عیب‌یابی

### ربات پاسخ نمی‌ده:

- Webhook رو چک کن:
```
https://api.telegram.org/bot<TOKEN>/getWebhookInfo
```

- Webhook رو دوباره تنظیم کن:
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=<WORKER_URL>
```

### مسدودیت کار نمی‌کنه:

- از دستور `/blocked` استفاده کن و ببین کاربر توی لیست هست یا نه
- آیدی رو درست کپی کن (بدون فاصله)
